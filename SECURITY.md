# Security

Reports can contain internal addresses, schema names, usernames and other assessment data. Credential reports created with `--reveal-secrets` contain full literal secrets. Keep reports and comparison keys out of public repositories and public issue trackers.

For a security issue in Iris Recon, send a minimal reproduction to **iriss.smith08@proton.me**. Use a local fixture and remove actual credentials, customer data and private targets.

Checks are limited in scope. Findings need review, and an assessment with no findings is not a security guarantee. See the README for module coverage and limitations.
